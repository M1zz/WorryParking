Parkir Kekhawatiran

Kebijakan Privasi

Berlaku sejak 19 September 2026

Singkatnya: Parkir Kekhawatiran tidak mengumpulkan data pribadi.

  • Tidak ada akun atau proses masuk, dan pengembang tidak mengoperasikan server apa pun.
  • Kekhawatiran yang kamu tulis dan riwayatmu hanya disimpan di perangkatmu.
  • Aplikasi tidak menggunakan SDK pihak ketiga untuk iklan, analitik, atau pelacakan.

1. Informasi yang disimpan di perangkatmu

Agar aplikasi berfungsi, hal berikut disimpan hanya di iPhone-mu. Pengembang tidak dapat mengaksesnya dan data itu tidak pernah dikirim ke mana pun.

Jika kamu mengaktifkan Cadangan iCloud atau cadangan komputer, data ini dapat disertakan dalam cadangan perangkat Apple bersama data aplikasi lain. Cadangan tersebut tunduk pada kebijakan privasi Apple dan tidak dapat diakses oleh pengembang.

2. Notifikasi

Pengingat penjemputan adalah notifikasi lokal yang dijadwalkan di perangkatmu. Notifikasi hanya menampilkan nomor petak (misalnya “P3 siap dijemput”) dan tidak pernah memuat teks kekhawatiranmu. Kamu bisa mematikannya kapan saja di Pengaturan > Notifikasi.

3. Pembayaran

Aplikasi ini tidak memiliki pembelian. Pengembang tidak menerima nama, email, atau data pembayaranmu.

4. Berbagi dengan pihak ketiga

Karena pengembang tidak mengumpulkan data pribadi, tidak ada data yang dibagikan kepada atau diproses oleh pihak ketiga.

5. Penyimpanan dan penghapusan

  • Geser ke kiri pada satu entri di catatan keluar untuk menghapusnya.
  • Menghapus aplikasi akan menghapus semua data yang disimpannya di perangkatmu.

6. Anak-anak

Aplikasi tidak mengumpulkan data pribadi dari siapa pun, termasuk anak-anak.

7. Pernyataan kesehatan

Parkir Kekhawatiran adalah alat bantu diri. Aplikasi ini bukan perangkat medis dan tidak menggantikan diagnosis atau pengobatan profesional.

8. Perubahan kebijakan ini

Jika kebijakan ini berubah, versi baru akan diterbitkan di halaman ini dengan tanggal berlaku yang baru. Setiap perubahan yang melibatkan pengumpulan data akan diumumkan di sini sebelum pembaruan aplikasi dirilis.

9. Kontak

Untuk pertanyaan seputar privasi, silakan buka issue di GitHub.
